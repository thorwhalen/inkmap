inkmap.viz

Visual overlays, for checking that a result is actually right.

Coverage maps are the kind of output that looks plausible when it is subtly wrong – a half-unit offset or a quarter-turn rotation of the model both produce a mask of the right shape, size and density. Looking at it is the cheapest way to catch that class of error, so this is a first-class part of the workflow rather than a nicety.

Only needs OpenCV and numpy; nothing here imports matplotlib.

inkmap.viz.REGION_COLORS: dict[int, tuple[int, int, int]] = {Region.OUTSIDE: (0, 0, 0), Region.MARGIN: (90, 90, 90), Region.BACKGROUND: (200, 140, 60), Region.FOREGROUND: (60, 90, 230)}

BGR colours per region. Foreground warm, background cool, margin neutral.

(H, W) float coverage -> BGR heatmap. Partial coverage is what to look at.

inkmap.viz.colorize_regions(region: ndarray) → ndarray[source]

(H, W) region labels -> BGR image.

inkmap.viz.overlay(image: ndarray, ink_map: InkMap, *, alpha: float = 0.45, draw_quad: bool = True, draw_grid: bool = False) → ndarray[source]

Blend the region map over the original image.

draw_grid overlays the fitted model grid, which is the fastest way to see a mis-fitted transform: if the lines do not sit on the mark’s own boundaries, every downstream number is wrong no matter how clean the mask looks.

inkmap.viz.panel(image: ndarray, ink_map: InkMap, *, crop: bool = True) → ndarray[source]

Four-pane contact sheet: original | overlay | coverage | measurement weight.

The last two panes are the ones worth studying. Coverage should show a thin soft fringe along every foreground boundary; weight should show that fringe eaten away, leaving only interiors. If weight is empty, the image cannot support a measurement.
