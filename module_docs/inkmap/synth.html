inkmap.synth

Synthetic scenes with exact ground truth.

Real photographs cannot validate a coverage map. Nobody can hand-label what fraction of a pixel is foreground, and no public dataset carries per-pixel coverage ground truth for printed marks – the document-binarisation benchmarks (DIBCO) are binary. So the only way to measure whether a 0..1 output is right is to render scenes whose true coverage is known analytically.

The trick that makes it exact: render the image from the coverage map. Supersample the model through a known transform to get true coverage, then form the clean image as 255 * (1 - coverage). Ground truth and stimulus are the same object by construction, and any degradation applied afterwards (blur, noise, gradient, glare, JPEG) leaves the ground truth correct.

Works for any model, so a text or logo pipeline is validated the same way as a QR one. Real photographs remain essential for detection rate – see inkmap.corpus.

inkmap.synth.render(model: Model | None = None, *, size: int | tuple[int, int] = 800, pixels_per_unit: float = 10.0, perspective: float = 0.0, rotation: float = 0.0, blur: float = 0.0, noise: float = 0.0, gradient: float = 0.0, glare: float = 0.0, jpeg_quality: int | None = None, samples: int = 8, rng: Generator | int | None = None) → Scene[source]

Render one synthetic photograph of model with exact ground-truth coverage.

Degradations are applied in capture order – geometry, then optics (blur, glare), then illumination, then sensor noise, then compression – because any other order models a camera that does not exist. perspective jitters the four corners by that fraction of the mark’s span; rotation is in degrees; gradient is the fractional illumination falloff across the frame.
