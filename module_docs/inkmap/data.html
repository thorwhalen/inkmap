inkmap.data

The real-photograph test corpus: 189 photographed marks in the wild (QR codes), from Wikimedia Commons.

Synthetic scenes (inkmap.synth) are the only way to validate a coverage value, because no photograph comes with per-pixel ink ground truth. But synthetic scenes cannot tell you whether detection works on a QR code printed on a curved bottle under a sodium lamp. The two test sets answer different questions and you need both.

Only the manifest ships with the package – titles, URLs, licences and attribution, about 100 KB. The images themselves are fetched on demand and cached, because ~120 MB of photographs has no business inside a wheel, and because redistributing them would mean carrying every attribution requirement into this repository.

Every image is CC0, public domain, CC BY or CC BY-SA. Attribution is in the manifest and attribution_text() will render it – if you publish results using these images, use it.

paths = data.fetch() # download + cache, returns local paths for path, meta in data.items(): # iterate cached images with their metadata

inkmap.data.cache_dir() → Path[source]

Where fetched images live.

Honours INKMAP_DATA_DIR, else the XDG cache location. Test data is neither code nor user configuration, so it does not belong beside the package: a wheel install would make the package directory read-only, and a reinstall would silently discard a 120 MB download.

inkmap.data.fetch(*, limit: int | None = None, dest: Path | None = None, pace: float = 1.1, attempts: int = 5) → list[Path][source]

Download the corpus (skipping anything already cached) and return local paths.

Commons rate-limits hard and answers with HTTP 429 rather than queueing, so requests are paced and retried with exponential backoff. A full cold fetch takes several minutes; it is incremental, so interrupting and re-running is safe.
