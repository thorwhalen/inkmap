inkmap

inkmap – per-pixel foreground coverage for photographed marks.

Given a photograph of a printed mark and a model of its shape, say for every pixel how much of it is foreground (the mark) and how much is background (the substrate) – as a continuous fraction, not a boolean.

The model is the seam. QR symbols, barcodes, printed letters and arbitrary artwork all go through one pipeline, because all a model has to do is answer “is this point, in my own coordinate system, foreground?”:

import inkmap
from inkmap import models

inkmap.find(photo)                                        # auto-detect QR/barcode
inkmap.find(photo, model=models.text_model("ABC"), quad=q)  # a printed word
inkmap.find(photo, model=models.RasterModel(art), quad=q)   # anything you can draw

The simplest call:

coverage = inkmap.foreground(photo)   # (H, W) float32 in [0, 1]

With geometry:

ink = inkmap.find(photo)              # an InkMap, or None
ink.placement.quad                    # (4, 2) corners -- a quadrilateral, not a
                                      # rectangle: perspective is expected
ink.coverage                          # (H, W) float32 area coverage
ink.region                            # OUTSIDE / MARGIN / BACKGROUND / FOREGROUND
ink.weight                            # (H, W) float32 safe-to-measure weighting

Measuring:

mask = inkmap.measurement_mask(ink)   # pure pixels, eroded clear of edges
result = inkmap.measure(photo, ink)
result.contrast                       # foreground minus background, linearised
result.measurability.ok               # False if the image cannot support this

Terminology

The two classes are foreground and background, never dark and light: dark/light describe appearance, and appearance inverts (white-on-black print, reflectance-reversed symbols, inverted imaging), so an appearance name would mean the mark in one image and the substrate in the next. Polarity carries that mapping explicitly. The continuous value is coverage, after ISO 12647-2:2013 3.1 area coverage. See docs/terminology.md.

class inkmap.InkMap(coverage: ndarray, region: ndarray, placement: Placement, polarity: Polarity = Polarity.FOREGROUND_IS_DARK, weight: ndarray | None = None, blur_sigma: float | None = None, metadata: dict[str, ~typing.Any]=<factory>)[source]

Per-pixel foreground coverage for one placement, plus the geometry it came from.

coverage is geometric area coverage: the fraction of each pixel’s area lying under foreground. It is not an optical/reflectance-derived coverage (which lateral light scattering in the substrate inflates – the Murray-Davies/Yule-Nielsen effect), and it is not a probability. See confidence() for that.

class inkmap.Model(*args, **kwargs)[source]

The shape of a mark, in its own coordinate system.

Implement this – or just duck-type it – to teach the package a new kind of mark. Two members are required; render() has a working default in BaseModel.

property extent: tuple[float, float]

(width, height) of model space, in the model’s natural units.

property feature_size: float

Size of the smallest feature that must be resolved, in model units.

A model unit is not a feature. A QR module is the smallest feature, so its feature size is 1. But a glyph rendered onto a 512-cell raster has strokes tens of cells wide, and a model unit there is far smaller than anything that must be resolved. Whether an image can support a measurement depends on pixels per feature, not pixels per unit, so this is what makes that judgement portable across model kinds.

BaseModel estimates it from the rendered shape; grid models override it with the exact value.

occupancy(u: ndarray, v: ndarray) → ndarray[source]

Foreground indicator at model coordinates (u, v).

u and v are float arrays of any matching shape. Returns an array of the same shape, boolean or float in [0, 1]. Points outside extent must return 0 – callers rely on that to bound the mark.

Must be vectorised: it is called with millions of points.

class inkmap.Placement(model: Model, transform: ndarray, quad: ndarray, locator: str = '', payload: str | None = None, refined: bool = False, score: float | None = None, metadata: dict[str, ~typing.Any]=<factory>)[source]

A located instance of a model: which shape, and where it sits in the image.

transform is the bridge the whole package is built on – a 3x3 homography from model space (the model’s own units, origin at its top-left) to image pixels. The quad is just its image under that transform, kept for convenience.

locator: str = ''

Which locator strategy produced this.

payload: str | None = None

Decoded content, when the locator happened to decode something. Never required: decoding is not the point, and a barely-deposited mark may locate but not decode.

property pixels_per_feature: float

Image pixels across the model’s smallest feature.

This is the resolution figure that governs whether a trustworthy measurement is possible – not pixels_per_unit. A model unit is not a feature: a QR module is both, but a glyph rendered onto a 512-cell raster has strokes tens of cells wide, so pixels-per-unit there would understate the real resolution by that factor and declare every image unmeasurable.

property pixels_per_unit: float

Image pixels per model unit.

For a QR symbol a “unit” is one module; for a barcode, one narrow bar; for a raster model, one raster cell. Use pixels_per_feature to reason about whether the image resolves the mark.

quad: ndarray

(4, 2) float32 image-space corners of the model’s extent, in the model’s own order (its top-left first), not re-sorted into image order. Re-sorting by coordinate sum/difference – a common idiom – silently mislabels corners once the mark is rotated past 45 degrees, which rotates the model and corrupts every derived mask while leaving it looking plausible.

score: float | None = None

Alignment score from refinement, if it ran. A proxy for geometric fit quality.

transform: ndarray

(3, 3) float64, model coordinates -> image pixels.

property units_per_pixel: float

Model units spanned by one image pixel, averaged over the two axes.

class inkmap.Polarity(value)[source]

Which apparent-brightness state the foreground corresponds to.

Carried explicitly so that no appearance word ever has to stand in for a physical class. Flipping this is the supported way to handle inverted print and inverted imaging, rather than inverting masks at the call site.

FOREGROUND_IS_DARK = 0

ink absorbs, so the mark reads darker than the substrate.

Type:

The usual case

FOREGROUND_IS_LIGHT = 1

the mark reads brighter than the substrate.

Type:

Reversed

class inkmap.Region(value)[source]

Four-way pixel classification.

Not a matting trimap: a trimap’s third class is “unknown/undecided”, whereas every class here is a decided statement about location.

BACKGROUND = 2

Bare substrate within the mark’s footprint.

FOREGROUND = 3

The mark itself – printed ink, toner, engraving, whatever laid it down.

MARGIN = 1

The clear surround a mark is specified to have – a QR quiet zone, a barcode light margin, the whitespace around a glyph. Guaranteed background, contiguous, and free of edge effects from neighbouring foreground, which often makes it a better reference region than the background inside the mark.

OUTSIDE = 0

Outside the mark and its margin.

inkmap.confidence(gray: ndarray, placement: Placement, coverage: ndarray, *, polarity: Polarity = Polarity.FOREGROUND_IS_DARK) → ndarray[source]

How much to trust the coverage value at each pixel, in [0, 1].

Distinct from coverage. Three things erode it, combined multiplicatively:

  • Model/image disagreement – where the observed value contradicts the modelled coverage, one of them is wrong. This is what catches foreground that failed to print, a torn label, or a mis-fitted transform.

  • Clipping – saturated or crushed pixels carry no photometric information.

  • Edge proximity – mixed pixels are inherently less certain, and their value depends on sub-pixel geometry known only to ~0.5 px.

inkmap.coverage_map(model: Model, transform: ndarray, image_shape: tuple[int, int], *, samples: int = 8) → ndarray[source]

Area fraction of each pixel covered by the model’s foreground, in [0, 1].

Each pixel is probed at samples**2 sub-positions on a regular grid at sub-pixel centres; each probe is back-projected into model coordinates and passed to Model.occupancy(). The mean is the covered area fraction – ordinary supersampled area coverage, the same quantity a renderer’s anti-aliasing computes.

Values are quantised to 1/samples**2, so samples sets the accuracy floor. Only the model’s bounding box is evaluated, so a mark occupying 2% of a 12 MP photo costs 2% of the work.

inkmap.find(image, **kwargs) → InkMap | None[source]

The largest mark in image, or None. See find_all().

inkmap.find_all(image, *, model: Model | None = None, quad=None, locators=('qr_zxing', 'qr_aruco', 'qr_opencv', 'barcode_zxing'), **kwargs) → list[InkMap][source]

Find every mark in image and compute its foreground coverage.

With model and quad, skips detection entirely and analyses that one placement – the path for marks no detector knows about. With neither, runs the locator cascade (QR and linear barcodes out of the box).

refine (default on) aligns the rendered model to the photograph, pinning the transform to sub-pixel accuracy; it is far more accurate than locator corners alone and costs a few milliseconds.

source picks where coverage comes from: "modelled" (default) computes it from the model – exact and lighting-independent, answering “where should the foreground be”. "observed" reads it from the photograph, answering “where is the foreground actually”, and so is the one that can see a printing defect.

inkmap.foreground(image, **kwargs) → ndarray[source]

Foreground coverage of the largest mark, (H, W) float32 in [0, 1].

All-zero if nothing is found – the one-liner never raises on a miss, so it can be mapped over a directory. Use find() to tell “no mark” from “a mark with no foreground”.

inkmap.locate(bgr: ndarray, gray: ndarray, *, locators: Sequence[str | Callable[[ndarray, ndarray], list[Placement]]] = ('qr_zxing', 'qr_aruco', 'qr_opencv', 'barcode_zxing'), first_hit: bool = False) → list[Placement][source]

Run locator strategies and merge their results, de-duplicating by position.

Strategies are tried in order. With first_hit=True the cascade stops at the first strategy that finds anything – cheaper, and usually right when you know there is one mark. Otherwise every strategy runs and results merge, which is what earns the recall when an image holds several marks that no single detector finds all of.

inkmap.measurability(ink_map: InkMap, *, min_pixels: int = 50) → Measurability[source]

Judge whether a foreground/background measurement can be trusted here.

Returning a number quietly biased by 30% is worse than refusing, so this is checked up front and attached to every Measurement.

inkmap.measure(image: ndarray, ink_map: InkMap, *, linearize: bool = True, flatten: bool = False, margin: int | None = None, robust: bool = True) → Measurement[source]

Aggregate image over the safe foreground and background pixels of ink_map.

image need not be the one the mark was located in: any frame registered to it works, which is the usual way to measure a different exposure, channel or modality using geometry established once on the sharpest frame.

linearize undoes sRGB encoding first – leave it on for anything from a normal camera pipeline, off for already-linear data. flatten divides out a fitted illumination field. robust reports medians alongside means; on real photographs they diverge exactly where something is wrong, which makes the pair a free diagnostic.

inkmap.measurement_mask(ink_map: InkMap, *, kind: str = 'foreground', purity: float = 0.999, margin: int | None = None) → ndarray[source]

Pixels safe to measure: geometrically pure, then eroded clear of edges.

kind selects "foreground" or "background". purity is the coverage threshold for “pure”; the default demands essentially total coverage, which is the point – a partially covered pixel biases the mean toward the other class.

This is the mask to use for a measurement. InkMap.foreground_mask() is for display and for anything that only needs a label.

inkmap.measurement_weight(coverage: ndarray, *, blur_sigma: float | None = None, radius: int | None = None, inside: ndarray | None = None, kind: str = 'foreground', sigmas: float = 2.0) → ndarray[source]

Blur-aware weight in [0, 1]: how safe each pixel is to measure.

Coverage says a pixel lies entirely under foreground. That is necessary but not sufficient: the point spread function leaks neighbouring signal into interior pixels, and that contamination has a different footprint from partial area coverage – so no coverage-based weighting removes it. The fix is spatial: require a pixel’s whole neighbourhood to be foreground, out to the radius the blur reaches.

Implemented as grayscale morphological erosion of the coverage map, which is exactly “the minimum coverage within radius r” – continuous rather than a hard mask, so a pixel one step from an edge is down-weighted rather than trusted or discarded.

Give either radius (pixels, wins if both are given) or blur_sigma, from which the radius is sigmas * blur_sigma.

inkmap.observed_coverage(gray: ndarray, placement: Placement, *, polarity: Polarity = Polarity.FOREGROUND_IS_DARK, yule_nielsen_n: float = 1.0, percentile: float = 5.0) → ndarray[source]

Apparent coverage read from the photograph itself (Murray-Davies).

Endmember values are estimated from the mark’s own pixels – its background region gives the substrate endpoint, its foreground core the solid endpoint – so no external calibration target is needed. Percentiles rather than extremes, so a specular highlight cannot define an endpoint.

yule_nielsen_n > 1 compensates for lateral light scattering in the substrate, which otherwise inflates apparent coverage above geometric coverage. n = 1 is plain Murray-Davies; the right value is substrate- and wavelength-specific and should be fitted, not guessed.

The result is apparent, not geometric, coverage. Do not silently substitute it for coverage_map().

inkmap.place(model: Model, quad, *, inclusive_pixel_corners: bool = False, locator: str = 'manual', **metadata) → Placement[source]

Place a model at a known quadrilateral – the universal escape hatch.

quad is four (x, y) image points in the model’s own corner order: the point corresponding to model-space (0, 0) first, then clockwise. Order matters and is not inferred: sorting corners by image position silently mislabels them once the mark is rotated past 45 degrees.

Use this for anything without a decoder – printed letters, logos, engraved marks – or when you already know where the mark is and only want the coverage machinery.

inkmap.srgb_to_linear(image: ndarray) → ndarray[source]

Undo the sRGB transfer function, returning float in [0, 1].

Averaging pixel values without this is a real error, not a nicety: sRGB values are perceptually encoded, so the mean of encoded values is not the encoded mean intensity. Any difference between two exposures compounds it. Apply before any arithmetic that claims to be about light.

The piecewise IEC 61966-2-1 curve, not the 2.2 power approximation.
